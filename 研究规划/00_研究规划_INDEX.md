# 研究规划 Prompt 索引

这个分区用于回答前置问题：**这个想法值不值得做？应该如何变成可研究的问题？接下来该读什么？**

它不是 reading note prompt，也不是写作 prompt。任务是先帮你做研究判断，再把确认后的方向交给阅读、写作或审阅工作流。

## 怎么选

| 场景 | 用哪个 |
|---|---|
| 我有一个章节困惑、导师反馈、方法问题或模糊方向，想变成可研究子问题 | [01_子问题与章节方向规划_prompt.md](01_子问题与章节方向规划_prompt.md) |
| 我有一个小论文、会议摘要或投稿想法，想判断是否可发展 | [02_论文与会议选题规划_prompt.md](02_论文与会议选题规划_prompt.md) |

## 推荐工作流

1. 先用 [../项目背景/快速上下文加载器_prompt.md](../项目背景/快速上下文加载器_prompt.md) 建立基础上下文。
2. 如果问题还很模糊，用 [01_子问题与章节方向规划_prompt.md](01_子问题与章节方向规划_prompt.md)（它会先用 Socratic 引导你）。
3. 确认方向后，根据输出的 `next prompt to use` 进入阅读系统：
   - 已有具体文献 → [../阅读/01_直接阅读已下载文献_prompt.md](../阅读/01_直接阅读已下载文献_prompt.md)
   - 只有关键词 → [../阅读/02_关键词检索下载评分阅读_prompt.md](../阅读/02_关键词检索下载评分阅读_prompt.md)
   - 来自反馈 / 章节问题 → [../阅读/03_根据反馈找Gap并补文献_prompt.md](../阅读/03_根据反馈找Gap并补文献_prompt.md)

## 输出原则

- 默认只在对话中输出规划，不自动写入文件。
- 只有用户确认后，才建议保存。
- 规划必须服务你的具体论文项目，不做泛泛的 academic brainstorming。
