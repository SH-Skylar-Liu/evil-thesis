# 引用格式转换 prompt

末段格式工具：在学术引用格式之间转换。它只管格式，不核查引用是否真实存在，也不在起草阶段用。

## 复制给 LLM 的 prompt

```text
请把我的引用从【源格式】转换为【目标格式】。你只负责格式转换，
不要核查引用真实性，也不要改动事实内容。

## 格式

- 源格式：[APA 7 / Chicago author-date / Chicago notes-bibliography /
  MLA 9 / Harvard / MHRA / IEEE / Vancouver / 其他]
- 目标格式：[同上选一个]

## 铁律

- anti-fabrication：只用我提供的字段转换。如果目标格式需要某字段
  （页码、出版社、出版地、卷期、DOI、访问日期等）而我没给，标 [缺：字段名]，
  绝不编造。
- 只改格式标点和字段顺序，不改作者、年份、标题、期刊名等事实。
- 中文 / 非英语文献按目标格式的相应规则处理；如该格式对中文文献规则不明确，
  照常转换并加一句说明。
- 如果我同时给了正文内引用（in-text）和参考文献条目（reference list），
  两者都按目标格式转换，并保持彼此一致。

## 输出

### 转换后的引用
[正文内引用 + 参考文献，按目标格式]

### 缺字段清单
| 引用 | 目标格式需要但缺失的字段 |
|---|---|

### 不确定 / 需我确认
- [例如：某条作者数超过格式的 et al. 阈值，列出处理方式；或某条无法判断文献类型]

## 待转换引用

[粘贴正文内引用 和 / 或 参考文献条目]
```
