# 章节拼装 prompt

> 这个 prompt 做的是 assembly，不是 rewriting。
> 它的工作：连接已有段落、删除重复、统一语气、写过渡句。
> 它不做的：改变论证立场、重写你已经写好的内容、判断论点是否正确。

## 复制给 LLM 的 prompt

```text
请帮我把以下段落草稿拼装成一个连贯的章节节段。

## 输入材料

请按以下顺序处理（这是我预期的大致排列顺序，你可以在拼装时调整）：

1. [粘贴或填段落 1]
2. [粘贴或填段落 2]
3. [继续添加]

## 这个节段的功能

[填，例如：
- "这是 Lit Review 第二节的主体，负责建立 X 概念的争议谱系"
- "这是 Methodology 的 3.1 节，负责引入分析框架"
- "这是 Discussion 的结尾，负责回应 RQ1 并过渡到限制"]

## 目标读者和写作目标

[填，例如：
- "thesis examiner，熟悉本领域"
- "投稿评审，跨学科读者"]

预期节段长度：[例如 800-1200 词]

## 拼装规则

你只能做以下操作，不能超出范围：

允许：
- 添加过渡句（段落之间的衔接，通常 1-2 句）
- 删除明显重复的内容（同一论点在两个输入文件里都有，合并成一次）
- 统一术语拼写（如 dataset vs data set，选一个保持一致）
- 轻微调整段落顺序（如果输入材料的顺序明显不对）
- 删除冗余的"本节将……"类的元叙述句

不允许：
- 改写已有段落的实质内容
- 添加新的论证或引用（如果发现某处需要引用但没有，标 [CITATION NEEDED: 描述]，不要自己填）
- 把两个论点合并成一个（即使它们看起来相似，保持它们分开，让我来判断）
- 改变引文的措辞或声明强度

## 输出

### 拼装后的节段（英文正文）

[连贯的英文段落，带过渡，不带列表]

**中文：** [对应的中文转述，仅对新增的过渡句翻译；已有段落的中文保持原文]

### 拼装说明

请在正文后说明：

**删除了什么**：[列出从哪个输入文件删除了什么重复内容，原因]

**重新排序了什么**：[如果调整了顺序，说明原顺序和新顺序，以及理由]

**添加的过渡句**：[列出每个新增的过渡句，及其连接的是哪两个段落]

**发现的问题（不在拼装范围内，供你参考）**：
- [论证层面的问题，例如"第2段和第4段之间存在逻辑跳跃，需要你决定如何处理"]
- [引用问题，例如"第3段的某个声明没有引用支撑，已标 CITATION NEEDED"]
- [结构问题，例如"第5段感觉更适合放在 3.2 节而不是 3.1 节，供参考"]

### 一致性核查

拼装完成后，请检查：

- [ ] 核心术语（[你的核心术语]）在全段中拼写和用法是否统一？
- [ ] 是否有段落在声明强度上比其他段落明显弱或强？
- [ ] 主动 / 被动使用是否一致？
- [ ] 句式长度是否过于单调？

原始输入文件不要修改。
```
