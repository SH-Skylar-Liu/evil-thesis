# 根据反馈找 Gap 并补文献 prompt

> **调用方式**：把这份笔记和审阅意见（或方法论章节草稿）一起发给 LLM，说"按照 reading workflow 执行"。LLM 会从头到尾逐步完成。
>
> **reading note 模板**：本 prompt 不再自带模板，统一复用 01_直接阅读已下载文献_prompt，只在阶段四说明本 workflow 的两点增量。

## 整体流程图

```
审稿意见 / 方法论章节草稿 / 导师反馈
        ↓
[阶段一] 提取 Gap + 关键词
        ↓
[阶段二] 文献搜索 + 存在性核验
        ↓
[阶段三] 候选文献筛选表 → 停下，等用户确认
        ↓
[阶段四] 逐篇精读 + 写 Reading Note → 每篇后停下等 feedback
        ↓
        完成
```

**铁律**：每个阶段完成后停下，等用户 feedback，不自动进入下一阶段。

## 复制给 LLM 的 prompt

```text
请按照我的反馈驱动阅读流程执行。

## 阶段一：从反馈提取 Gap 与关键词

### 输入
- 审阅意见 / 导师反馈 / 章节诊断
- 可选：相关章节草稿（用于定位指向）

### 执行步骤

1. 识别批评结构：区分"必须解决的核心问题"（Major Revision）和
   "建议性改进"（Minor Suggestion）。不要把 minor 过度解释成不存在的 major gap。
2. 提取方法论 / 理论 / 文献 Gap：将批评映射到具体的缺口，用代号标记
   （Gap A、Gap B、Gap C……）。
3. 为每个 Gap 生成搜索关键词组合：
   - 理论/概念词
   - 方法词
   - 领域词
   - 时间限定（如优先最近 5-8 年）

### 输出格式

Gap A — [一句话描述]: 
  关键词组合1: "xxx" + "yyy" + "zzz"
  关键词组合2: ...

Gap B — [一句话描述]:
  关键词组合1: ...

如果反馈结构不清楚、找不到明确意见，先停下问我，不要硬编。

## 阶段二：文献搜索

### 工具优先级

| 场景 | 工具 |
|---|---|
| 精准查找某篇已知论文 | 直接搜标题 + DOI |
| 探索某个 Gap 的文献 | 用关键词组合搜索，优先 Google Scholar / Semantic Scholar |
| 检查 OA 可及性 | 搜标题 + "filetype:pdf" 或访问 unpaywall/arXiv |
| 检查本地 Zotero 是否已有（如适用） | 扫描 Zotero storage |

### 搜索量标准

- 每个 Gap 搜索 5-10 篇候选，最终筛选至 2-4 篇最相关；
- 如果某个 Gap 找不到高度相关文献，如实说明，不凑数。

### 存在性核验（必做）

每篇候选进入筛选表前，必须在 Semantic Scholar / OpenAlex / Crossref
至少一个库里核到（标题 + 作者 + 年份匹配）。核不到的，标注
[未核实，可能不存在]，不要凭印象或记忆把文献写进表里。

## 阶段三：候选文献筛选表

搜索完成后，输出一份候选文献表，停下等用户确认再开始阅读。

## 候选文献表

| # | 作者/年 | 标题 | Gap | 来源·核验 | 相关度 | 获取状态 | 建议操作 |
|---|---------|------|-----|---------|--------|---------|---------|
| 1 | Smith 2023 | "..." | A | 期刊(peer-reviewed)·已核 | ★★★★★ | OA PDF 已下载 | 精读 |
| 2 | Jones 2021 | "..." | B | preprint·已核 | ★★★ | Zotero 已有 | 精读 |
| 3 | ... | ... | C | [未核实，可能不存在] | ★★ | 需用户获取 | 可选 |

「来源·核验」列：
- 来源类型：期刊(peer-reviewed) / preprint / 专著或编著章节 / 报告 / 会议 / 灰色文献 / 疑似 predatory；
- 核验状态：已核 / [未核实，可能不存在]。

相关度标准（只评"与 Gap 多相关"，不等于来源质量）：
- ★★★★★ (5★)：直接解决 Gap，方法论核心资源；
- ★★★★ (4★)：高度相关，构成论证块；
- ★★★ (3★)：相关但有距离，适合脚注级引用；
- ★★ 以下：不建议纳入。

等待用户：
- 确认哪些论文纳入阅读；
- 提供用户自行获取的 PDF 路径；
- 确认阅读顺序（优先级）。

## 阶段四：逐篇精读 + 写 Reading Note

### 铁律
- 每次只读一篇，写完一篇后停下等 feedback，再继续；
- 不自动连续读写多篇；
- 用户说"继续"后才读下一篇。

### 模板（统一复用 01_直接阅读已下载文献_prompt）

- 4★ / 5★ → 用 01 的 4★ / 5★ 高相关模板
- 3★ → 用 01 的 3★ 中等相关模板

本 workflow（反馈 / Gap 驱动）在 01 模板基础上的两点增量：

1. 「为什么相关」里必须指明对应哪个 Gap（Gap A / B / C）；
2. 把「可以怎样用于我的论文」改为「在某章节中的精确用途」并设为必填：
   说明对应 Gap 的具体位置、在哪个论证步骤如何引用、提供什么论证功能
   （辩护 / 对话 / 背景 / 反例）、不适合用在哪里。

01 模板已内置：知识隔离、核心发现带出处、对话栏标分歧。

## 写作规范（所有笔记通用）

### 语言
- 正文讨论：中文
- 学术英文内容（摘要、核心发现、可引用原句）：英文 + **中文：** 转述

### 引用与知识隔离
- 不虚构引用：不确定时用 hedging 语言（appears to argue / suggests / may address）；
- 不用夸大评价词：不写 foundational / definitive / most cutting-edge；
- 引用原句必须基于实际读到的文本，并尽量标注页码；
- 知识隔离：只依据眼前 PDF 文本，不用记忆里"这篇大概讲什么"补全；
  凭记忆而非文本得出的，标 [来自记忆，需核实]。

### 禁止操作
- 不更新已有文件的链接或索引；
- 不自动连续：写完一篇后必须停下；
- 不补充未读内容：只写实际读到的部分，缺失在 `unsure` 字段说明。

## 调用示例

"按照 reading workflow 执行。这是导师的反馈：[粘贴]。
方法论章节草稿在 [路径]。"

或（跳过前三阶段直接读某篇）：

"跳到阶段四，按照 reading workflow 读这篇：[路径]，
它是 4★，对应 Gap B。"
```
