## Routing discipline

- 如果你还不能说清"为什么读这些文献"，先去 [../研究规划/01_子问题与章节方向规划_prompt.md](../研究规划/01_子问题与章节方向规划_prompt.md)。
- 如果你能说清主题，但没有具体文献，用 02。
- 如果任务来自导师或 reviewer 的批评，用 03。
- 如果已经确定具体 PDF，用 01。
- 如果已经有 4-10 篇 reading notes，不要继续搜索，转去写作系统。

## 三个阅读 prompt 的区别

### 1. 直接阅读已下载文献

用在你已经知道要读哪篇的时候。

输入：PDF 路径 / Zotero key / DOI / 标题。
输出：一篇正式 reading note + 阅读报告 + 后续升级建议。
停下：每读完一篇后停下，不自动读下一篇。

### 2. 关键词检索下载评分阅读

用在你只知道主题或关键词的时候。

工作流：拆关键词 → 搜索 → 下载或定位 PDF → 评分 → 停下等确认 → 读最相关的。
停下：候选评分表后；每篇 reading note 完成后。

### 3. 根据反馈找 Gap 并补文献

用在你已经有审稿意见、导师反馈或章节问题诊断的时候。

工作流：从反馈提取 gap → 转关键词 → 找文献 → 评分 → 停下等确认 → 读。
停下：gap 提取后（如批评结构不清楚）；候选筛选表后；每篇 reading note 后。

## 防幻觉护栏（三个 prompt 通用）

- **知识隔离**：只依据眼前 PDF 文本，不用训练记忆补全；凭记忆得出的内容标 `[来自记忆，需核实]`。
- **引用存在性核验**（02 / 03）：候选文献须在 Semantic Scholar / OpenAlex / Crossref 至少一库核到才入表，核不到标 `[未核实，可能不存在]`。
- **来源质量分级**（02 / 03）：候选表用「来源·核验」列把来源质量与相关度分开。
- **核心发现带出处 + 对话标分歧**：reading note 模板（01）内置，03 复用。

`03` 不另设 reading note 模板，统一复用 `01`，只声明 Gap 驱动的两点增量。

## Reading Handoff

当研究规划或候选筛选完成后，建议用这个格式交接到阅读：

```markdown
## Reading Handoff

- source task:
- confirmed direction:
- confirmed papers:
- reading order:
- PDF / Zotero status:
- special focus:
- stop after:
```
