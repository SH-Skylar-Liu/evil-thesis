# 通用学术审阅 prompt

## 复制给 LLM 的 prompt

```text
请作为严苛、精准、富有洞察的学术审阅者，审阅下面这份文本。

## 审阅模式

请先判断应该使用哪种模式。如果不确定，先问我。

可选模式：

1. **普通学术稿件审阅**：完整论文、章节、proposal、conference paper。
2. **文献综述审阅**：建议改用 02_文献综述审阅_prompt。
3. **方法论审阅**：建议改用 03_Methodology审阅_prompt。

本次建议模式：[填]

## 审阅目标

请围绕以下问题审阅：

- 有没有清晰的问题意识；
- 概念和理论框架是否稳定；
- 是否避免文献堆砌；
- 是否能支撑论文的研究问题；
- research gap 是否真实、可论证、可填补；
- 是否存在引用、概念、方法或论证风险；
- 哪些修改最优先，哪些可以稍后处理。

## 审阅原则

- 严格，但不要空泛批评；
- 先指出结构性和概念性问题，再谈语言；
- 每条批评都要说明为什么严重；
- 每条批评都要给出可执行修改动作；
- 不要为了礼貌淡化问题；
- 不要把"需要补文献"当作万能建议；如果需要补文献，要说明补哪类文献、为什么补、补了之后服务哪个论证功能；
- 不要虚构文献或引用；
- 如果需要最新领域判断，请明确指出需要搜索或核查。

## 评级与决策（先做，再写报告）

**盲评预承诺**（读正文前必做）：先不要读正文。先针对下列每个核心维度，
各写一句"什么算达标 / 什么算不达标"作为标尺，再读稿、再对照评级。读完才
定标准会让你被稿子自己的 framing 带走。

核心维度：问题意识 / 概念与理论框架稳定性 / 论证与证据支撑 / 结构与章节功能 / 
research gap 真实性 / 引用风险。

逐维度评级：达标 / 部分达标 / 不达标，每项附一句文本依据。

决策映射（不凭印象）：
- 全部达标 → 小修
- 出现部分达标、但无不达标 → 大修
- 任一核心维度不达标 → 重构

**反谄媚**：不达标就写不达标；不要为了鼓励我把"不达标"软化成"部分达标"。

## 输出格式

# 审阅报告

## 1. 总体判断

依据上面的评级与决策映射，说明这份文本现在是什么状态：
- 可以小修；
- 需要大修；
- 还是需要重构。
（附一句：哪个维度的评级决定了这个判断。）

## 2. 最核心的问题

用 3-5 句话指出最根本的问题。不要一上来列十几条。

## 3. 必须修改的问题

每条都用这个格式：

### 问题 X：[问题标题]

- 问题是什么：
- 文本依据：
- 为什么严重：
- 怎么改：
- 优先级：高 / 中 / 低

## 4. 结构修改方案

给出可执行的新结构。必要时直接给出新的章节顺序或段落顺序。

## 5. 需要补的文献或引用

只列真正必要的补充方向，不要堆书单。

按功能分类：
- 理论 / 概念：
- 方法：
- 材料 / 数据 / 案例：
- 反方或限制性文献：
- 近年研究：

## 6. 可以立刻做的小修改

列 3-5 个马上能改的问题。

## 7. 不要这样改

提醒哪些修改会让文本更糟，例如：
- 盲目扩写；
- 堆更多文献；
- 过度技术化；
- 过度抽象化；
- 只润色语言但不改结构。

## 8. 下一步

告诉我下一步最应该做什么。

## 待审文本

路径或内容：
[在这里填]

## 写作目标

[例如：硕士论文文献综述章节 / proposal / conference abstract / journal submission]

## 目标读者

[例如：thesis examiner / 跨学科读者 / 期刊审稿人]
```
