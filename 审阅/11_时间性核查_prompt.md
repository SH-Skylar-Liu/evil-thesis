# 时间性与时代错位核查 prompt（可选）

> 这是一个专门给**历史材料写作**用的小核查。如果你的研究不涉及历史材料，可以跳过这个 prompt。

历史材料分析最容易犯的不是事实错，而是**时间错位**——用现在的眼光、术语或因果框架去套历史材料。这个 prompt read-only，只指出不改写。

## 复制给 LLM 的 prompt

```text
请对下面这段文字做"时间性核查"。你的任务是只找时间维度上的错误，不做通用审阅、
不改写正文。

## 背景

我研究涉及历史材料。因此存在两个时点：
①材料的时点（材料 / 事件发生的年代）
②分析的时点（我现在用 [当代] 的方法在看）

很多错误来自把这两个时点混为一谈。

## 逐条核查这五类时间性失误

1. **时代错位引用 / 概念（anachronism）**：把一个晚出现的概念、术语、方法或来源，
   当成能描述或影响更早的对象。例如用一个 2010 年代才提出的理论术语去描述 1970 
   年代材料"本身就具有"的特征，而没有说明这是回溯性的分析框架；或暗示某来源
   影响了比它更早的东西。

2. **因果倒置 / 伪因果（causal inversion）**：把时间上同期或后发的关系写成因果。
   例如"X 的变化导致了 Y 的转变"，而证据只支持"同期共现"。

3. **historical "now" 误用（deictic present）**：用 today / current / now / 
   contemporary / 当下 / 如今 指代历史材料，模糊了分析时点和材料时点。例如
   "these texts currently present X as..."——它们不是 currently，是在它们的年代。

4. **回溯算术（retrospective arithmetic）**：年代、跨度、"X 年间""近年来"的计算或
   表述错误；或用"近年"指一个其实很久远的时期。

5. **未兑现的比较基准（unmaterialized comparator）**：拿一个还不存在、还没产出的
   结果或语料当对照。例如把分析结论建立在"等下一阶段跑完就会有的"数据上，
   当成已有。

## 输出

| # | 类型 | 文本依据（引原句） | 为什么是时间性问题 | 改法建议 |
|---|---|---|---|---|
| 1 | deictic present | "..." | 把 1990s 材料写成 currently | 改为过去时 / 限定到具体年代 |

最后一句总结：哪一类失误最多，最该先处理哪一条。

## 约束

- 只查时间维度，不顺手做通用审阅。
- 不编造日期 / 年份；不确定材料或来源年代时，标 [需确认年代]，不臆测。
- 如果某处"看起来像时代错位"但其实是合理的回溯性分析框架（已说明是当代视角），
  不要误判为错误。

## 待查文本

[粘贴或填路径]

相关时间信息（可选）：
[例如：材料年代 1960-2000；所用某方法的发布年份；某来源的出版年]
```
