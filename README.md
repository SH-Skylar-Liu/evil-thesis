# Evil-thesis-skills 研究生论文邪修工具箱

研究生毕业论文 / 学位论文工作流工具包。一套**按真实任务分区**的 prompt 库，覆盖文献阅读、研究规划、章节写作（Introduction → Conclusion）、与结构化学术审阅。

> 适用对象：硕士研究生、taught postgraduate dissertation、research master 论文写作者。

## 这是什么

一套专治论文拖延、文献失控、导师反馈听不懂、章节写成散文、引用真假难辨的黑魔法 prompt 库。

它不负责安慰你“写得很好”，它负责冷酷地问：

- 你的 research gap 真的存在吗？
- 这段 claim 有证据吗？
- 你是不是在用 citation 装饰段落？
- 这个 methodology 考官一问会不会塌？
- 你的 Discussion 是在解释 findings，还是在复读 Results？
- 你说 contribution，证据呢？

## Evil Thesis 的邪修之处在于：

它会把一个混沌的研究生，从“我好像有个想法”一路拎到：

```text
研究问题 → 文献路线 → reading notes → evidence pack → 章节结构
→ 段落草稿 → 风险检查 → 引用核查 → 再审追踪 → 提交前自救
```

它的核心法术包括：

- **反谄媚术**：不达标就说不达标，不给你情绪按摩。
- **引用验尸术**：检查 citation 是真文献、真支持，还是纸糊的护身符。
- **导师反馈炼金术**：把“这里不清楚”炼成 action list。
- **论点压力测试**：先替考官攻击你，免得答辩当天现场渡劫。
- **章节缝合术**：把散落段落缝成有骨架、有证据、有方向的一章。
- **幻觉封印**：不知道就标 `[需核实]`，不许模型装懂。

## 设计原则

1. **先路由，再执行**：prompt 必须说明什么时候用、什么时候不用，避免一个 prompt 承担所有任务。
2. **先决策，再写入**：规划、搜索、候选筛选默认先在对话中输出，等用户确认后再写入。
3. **阶段性 checkpoint**：凡是会改变方向、文件状态或优先级的步骤，必须停下等用户确认。
4. **质量门优先**：宁可输出"不确定 / 需要用户确认"，也不要编造 citation、路径或文献观点。
5. **反谄媚 + 让步阈值**：不达标就写不达标；不被用户辩解一下就软化立场。
6. **知识隔离**：只依据用户提供的材料和眼前文本，不用模型记忆补全。

## 怎么用

最简单的方式：

1. 复制 [项目背景/快速上下文加载器_prompt.md](项目背景/快速上下文加载器_prompt.md) 给 LLM，让它知道你的研究背景。
2. 打开 [使用指南.md](使用指南.md)，按你现在的任务找对应分区。
3. 复制对应 prompt 的 `text` 代码块整段给 LLM（不要只截一半，护栏都在里面）。
4. 让 LLM 在 checkpoint 停下时，你检查、确认、再让它推进。

进阶：

- 在 Claude Code / Cursor / Windsurf 里把这个文件夹作为 skill / context 引用。
- Fork 后按自己专业改写（例如把双语输出改成纯中文、把文献综述审阅的领域换成你的学科）。

## 双语输出

国际研究生常需要中英对照来核对意思与导师反馈。默认：**学术正文英文为主，紧接 `**中文：**` 转述**。如只写中文论文，复制 prompt 时把"双语"改成"中文"即可。
