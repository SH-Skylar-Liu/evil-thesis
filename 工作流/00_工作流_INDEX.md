# 工作流 Prompt 索引

工作流分区放两类东西：

1. **工程标准**：怎么造 / 改 prompt（Prompt Standard）。
2. **可复用记录工具**：实验 / 数据 / 访谈 / 编码会议等记录的标准化 prompt。

## 文件

| 场景 | 文件 |
|---|---|
| **Prompt 统一标准（造 / 改 prompt 时必读）** | [PROMPT_STANDARD.md](PROMPT_STANDARD.md) |
| 跑完实验 / 编码会议 / 数据收集后立即结构化记录 | [01_实验或数据记录_prompt.md](01_实验或数据记录_prompt.md) |

## 为什么需要"记录"prompt

研究的可复现性 / dependability 不靠最终论文写作回忆，而靠**当下立刻记录**。
每次：
- 跑完一组数据；
- 做完一次抽样；
- 跟参与者做完一次访谈；
- 开完一次编码协商会议；
- 调完一组模型参数；

都应该用结构化方式记录下来。等到 Methodology / Results 写作时，这些记录
就是 Evidence Pack 的来源。
